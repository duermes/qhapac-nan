# Iconos personalizados del mapa

Coloca archivos SVG autocontenidos en esta carpeta. Se usan los mismos recursos
en Hatun Wasi, Chaski, mapa 2D/3D y leyenda. Si falta un archivo o no es válido,
se utiliza el icono vectorial integrado actual. No se requieren todos los archivos.

| Archivo | Tipo de punto |
| --- | --- |
| base.svg | Base |
| habitat.svg | Hábitat |
| antenna.svg | Antena |
| rover.svg | Rover (el propio conserva su halo) |
| astronaut.svg | Astronauta |
| waypoint.svg | Punto de ruta |
| poi.svg | POI científico |
| sample.svg | Muestra |
| rover_sample.svg | Muestra oficial de Perseverance |
| orbital.svg | Detección orbital de Mars Trek |
| landmark.svg | Infraestructura o estación |
| hazard.svg | Peligro observado o exclusión |
| laboratory.svg | Laboratorio |
| lava_pit.svg | Puntos antiguos de fosa de lava (ya no se crean desde el selector) |

Recomendado: viewBox="0 0 24 24", fondo transparente, trazos y rellenos con
colores explícitos legibles sobre terreno oscuro. Evita imágenes externas,
fuentes, scripts o recursos remotos. Recarga la página después de cambiar un SVG.
El distintivo V de un móvil virtual se dibuja aparte y no depende del SVG.
